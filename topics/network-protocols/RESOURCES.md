# Network Protocols — Resources

## Primary Sources

- [Node.js: node:net API](https://nodejs.org/api/net.html) — Official docs for TCP sockets
- [Node.js: node:dgram API](https://nodejs.org/api/dgram.html) — Official docs for UDP
- [Node.js: node:dns API](https://nodejs.org/api/dns.html) — Official docs including lookup() vs resolve() considerations
- [Node.js: node:tls API](https://nodejs.org/api/tls.html) — Official docs for TLS/SSL

## Protocol Foundations

- [Cloudflare: What is TCP/IP?](https://www.cloudflare.com/learning/ddos/glossary/tcp-ip/) — Clear, reliable overview
- [Cloudflare: What is DNS?](https://www.cloudflare.com/learning/dns/what-is-dns/) — DNS resolution chain explained
- [Cloudflare: TLS Handshake](https://www.cloudflare.com/learning/ssl/what-happens-in-a-tls-handshake/) — Visual step-by-step
- [Cloudflare: What is HTTP/3?](https://www.cloudflare.com/learning/performance/what-is-http3/) — QUIC and UDP's future role
- [MDN: TCP](https://developer.mozilla.org/en-US/docs/Glossary/TCP) — Concise MDN glossary entry
- [MDN: UDP](https://developer.mozilla.org/en-US/docs/Glossary/UDP) — Concise MDN glossary entry

## Deep Dives

- [RFC 793: TCP Specification](https://www.rfc-editor.org/rfc/rfc793) — The original TCP spec (heavy reading)
- [RFC 768: UDP Specification](https://www.rfc-editor.org/rfc/rfc768) — Very short (3 pages) — worth reading
- [RFC 9000: QUIC](https://www.rfc-editor.org/rfc/rfc9000) — The QUIC transport protocol spec
- [High Performance Browser Networking (Ilya Grigorik)](https://hpbn.co/) — Free book, excellent on TCP/UDP/TLS performance
